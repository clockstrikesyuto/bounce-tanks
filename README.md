# みんなのトランプ

スマホ優先のブラウザ向けトランプゲーム集。1人CPU戦とオンラインルーム対戦を同じ基盤で扱います。

## 収録 20 モード
大富豪 / ページワン / ババ抜き / ジジ抜き / 七並べ / ダウト / 神経衰弱 / スピード / 戦争 / インディアンポーカー / セブンブリッジ / ラミー / ブラックジャック / テキサスホールデム / ハーツ / スペード / ナポレオン / ゴニンカン / 51 / クロンダイク

## CPU
EASY / NORMAL / HARD。CPUも人間と同じ公開情報と合法手インターフェースを使用し、隠し札を直接参照して強くする方式にはしません。

## オンライン
4桁ルームコード、QR参加、WebSocket同期、ホストによるCPU追加・難易度変更、ゲーム終了後の再戦/別ゲーム、ルーム内総合ポイントに対応します。

## 開発上の注意
初期版ではナポレオン、ゴニンカン、テキサスホールデム等の複雑な宣言・競り・ベット部分は安全に動作する標準簡易ルールから開始しています。各ゲームは独立モジュール化しているため、正式ルールやローカルルールを段階的に追加できます。クロンダイクも初期版は基本的な山札・組札操作からの実装です。

## Run
```bash
pip install -r requirements.txt
uvicorn bootstrap:app --reload
```
